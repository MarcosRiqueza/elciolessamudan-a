# Lessa Mudanças

Website institucional desenvolvido para a **Lessa Mudanças**, com foco em apresentar os serviços da empresa, facilitar o contato com clientes e oferecer uma presença digital profissional.

## 📋 Sobre o projeto

O **Lessa Mudanças** é um projeto web desenvolvido com uma interface simples, moderna e responsiva, pensado para facilitar a apresentação dos serviços de mudança e transporte da empresa.

O projeto foi desenvolvido como parte do portfólio de desenvolvimento web, utilizando tecnologias fundamentais do Front-End.

## 🚀 Funcionalidades

* Página institucional da empresa
* Apresentação dos serviços
* Layout responsivo para diferentes tamanhos de tela
* Seção de contato
* Navegação entre as seções da página
* Elementos visuais relacionados aos serviços de mudanças
* Interface desenvolvida com foco em simplicidade e facilidade de uso

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura e conteúdo da aplicação
* **CSS3** — estilização, layout e responsividade
* **JavaScript** — interações e funcionalidades da página
* **Git** — controle de versão
* **GitHub** — hospedagem e gerenciamento do código-fonte

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/MarcosRiqueza/elciolessamudan-a.git
```

### 2. Entre na pasta

```bash
cd elciolessamudan-a
```

### 3. Abra o projeto

Abra o arquivo `index.html` diretamente no navegador ou utilize o **Live Server** no Visual Studio Code.

## 🌐 Deploy

O projeto pode ser publicado utilizando plataformas de hospedagem para aplicações Front-End, como o **Netlify** ou **GitHub Pages**.
